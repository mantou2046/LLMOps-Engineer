状态速查 遇到不认识的字段看这里

READY 0/1 但 STATUS 是 Running —— 这是最容易误判的一种。它说明容器在跑， 但 readiness 探针失败了，所以 K8s 把它的 IP 从 EndpointSlice 摘掉了。 请求打不到它，但它不会被重启（RESTARTS 保持 0）。先看下面这张表：
readiness 失败摘流量、不重启。症状：Service 无响应但 Pod 看着正常
liveness 失败重启容器。症状：RESTARTS 持续增长
startup 失败超时后杀容器。启动期 liveness/readiness 都不执行
137128+9（SIGKILL）→ 通常 OOMKilled，看 limit 是不是太小
143128+15（SIGTERM）→ 被优雅终止，常见于滚动更新
