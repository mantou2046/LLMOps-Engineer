## 0. 一句话口径（面试版，背下来）

> 「我给 RAG 生成端改了输出格式约束，用 10 题配对 A/B 加两把不读回答的噪声标尺量了一遍：目标指标只动 +0.0256，逐题标准差却有 0.2468，faithfulness 反而回退 0.0714，所以判定**不采纳**。这周没有提升数字，产出是一套能证明『一次改动该不该上线』的评估闭环——50 题 golden set、四项全量基线、分组报分、独立裁判、非 LLM 的 CI 门禁和 DEC-039~046 八条决策。」

配套三要素（缺一不可）：**改了什么、哪个指标动了多少、有没有副作用**。只说「提升了」等于没说；本周三要素是「改输出格式 / AR +0.0256 / faithfulness −0.0714 + 回答变形」。

## 2. 改动前 / 后对比数字

### 2.1 主实验：生成 prompt 单变量 A/B（D5，判定不采纳）

**改了什么**：生成端 system prompt 第 3 条，从「2–4 句、直接给结论和依据、不要复述问题」改成「1–2 句、首句带问题关键对象、第二句给依据、显式禁元信息与客套」；第 1、2、4 条逐字不变。A/B 回答与检索上下文固定，唯一变量就是这一条。

**改动确实生效**：平均回答 **139.7 → 118.4 字**，带「根据资料」「块 N」元信息的题 **4 → 1**。这两条是可量化的「改动效果」，不是指标提升。

**配对 10 题 · 独立裁判 `glm-5.3-flash`**（正本 `evals/ATTRIBUTION.md` §独立裁判交叉验证）：

| 指标 | 改动前 A | 改动后 B | Δ | 判读 |
| --- | --- | --- | --- | --- |
| faithfulness | 0.9514 | 0.8800 | **−0.0714** | 回退（副作用） |
| answer relevancy（目标） | 0.7647 | 0.7903 | **+0.0256** | 小量，逐题 σ **0.2468** 盖过 |
| context recall（噪声标尺） | 0.8183 | 0.7983 | −0.0200 | 理论上不读 response、应恒等，实测漂移 |
| context precision（噪声标尺） | 0.8810 | 0.8976 | +0.0167 | 同上；旧裁判版本这一项全 NaN |

**旧裁判交叉验证**（`deepseek-v4-flash`，与生成同模型）：faithfulness 0.9214→0.8000（−0.1214）、AR 0.6223→0.6269（+0.0046）、CR 0.8667→0.8741（+0.0074）。确定性余弦 A 0.7560 → B 0.7741 两次逐题完全一致，证明换裁判时唯一变量仍是 prompt。

**四条读数**：

1. **判定：不采纳，DEC-045 不改。** 逐题 AR 5 涨 3 跌 2 平、σ 0.2468、|Δ| 均值 0.1646，方向不稳；faithfulness 明确回退。
2. ⚠️ **不能套旧版「变化小于噪声」的原话**：新裁判下 AR Δ +0.0256 略大于两把噪声标尺（|CR| 0.0200、CP 0.0167）。正确说法是「**逐题波动远大于均值变化，加上 faithfulness 回退，不值得上线**」。
3. ⚠️ **「同模型自评偏高」的简单预期没被证实**：换独立裁判后绝对值整体平移（AR A +0.1424 / B +0.1634），同模型裁判给的分反而更低，更像两个裁判的口径差异；能确定的是**配对结论对裁判不敏感**，跨裁判绝对值不可直接比。
4. ⚠️ **`g002` 那次误拒答不是系统性倾向**：15 题拒答 / boundary 扩展实验里，12 道应拒答题 A/B 零翻转、boundary 误拒答 1→0（见 §2.4）。周复盘别把单题现象写成普遍规律。

### 2.2 检索层：rerank 复核（DEC-042，判定默认不开）

按 DEC-042 当初写的「等 golden set 与 RAGAS 四项出来再重评」，前置条件 11/8 集齐后复评：分层抽 20 道可答题，**基线 top-5 与 D4 逐字校验 20/20**，只换排序（RRF top-5 → `bge-reranker-base` 重排 top-10→top-5）。

| 项 | 改动前 RRF | 改动后 rerank | 差 |
| --- | --- | --- | --- |
| context precision | 0.7843 | 0.8451 | **+0.0608**（σ **0.2399**，7 涨 5 跌 8 平） |
| atoms 覆盖率 | 0.7100 | 0.7783 | +0.0683 |
| 精排延迟 | — | P50 **4545 ms** / P95 5193 ms | 约 1100× 向量查询 |

**结论：默认不开**，理由从「关键词判据量不了语义排序」升级为「用正式 CP 判据复评后，均值收益落在逐题波动里、代价是每查询约 4.5 秒」。见 `evals/RERANK_RECHECK.md`、DEC-042 复核补记。

### 2.3 对照坐标（不是「改动前后」，别混用）

- **50 题全量基线**：faithfulness 0.9434 / AR 0.4768 / CR 0.8113 / CP 0.8591。
- **分组**：`single_hop` 29 AR 0.6269；可答题 38 AR 0.6108；`refuse` 12 AR **0.0524** / CP **1.0000**；`boundary` 3 AR 0.3599。把 12 道拒答混进全量均值会把 AR 从 0.6108 拉到 0.4768。

- **门禁**：38 题 `IDBasedContextRecall@5` = 0.8421，阈值 0.65；CI 只跑 20 题抽样子集。

### 2.4 样本扩展：拒答 / boundary 纳入配对（11/8 晚间，佐证判定）

15 题（12 refuse + 3 boundary）A 组逐字复用 D4 回答，B 组同模型同通道重新生成、只换 prompt 第 3 条；控制变量校验 15/15 一致。

| 组 | 行为分（主判据） | faithfulness Δ | 旁证 |
| --- | --- | --- | --- |
| `refuse` 12 | A/B 均 11/12 正确拒答、**零翻转** | −0.1111 | CR 理论恒等却漂 **+0.2500**、CP 11/11 恒等 |
| `boundary` 3 | 误拒答 **1 → 0** | −0.0222 | AR Δ +0.4081，但 n=3 只作线索 |

结论：改动没有造成拒答行为退化，判定维持不采纳；应拒答题的 `reference` 写的是期望行为而非事实答案，ragas 绝对值不可解释，只作分组旁证。`g049` B 组 CP 两次 180 秒超时按「同一步失败两次即停」止损，留 1 个 NaN（119/120 齐全），未回填、未编数。见 `evals/REFUSAL_AB.md`。

## 3. 数字的口径边界（面试被追问时先说这个）

1. **跨裁判绝对值不可直接比**：同模型裁判与 `glm-5.3-flash` 有明显的尺度平移；能跨裁判比较的是**配对 Δ 与判定方向**。
2. **全量 50 题 ≠ 旧 10 题小样**：题库结构（可答题 vs 含 12 拒答 / 3 boundary）和裁判都换了，均值下移不是系统退化。
3. **拒答题的 ragas 四项不作召回 / 精度解释**：`reference` 是期望行为；CR 不读 response 却漂 0.25 就是证据。以确定性行为判据为主。
4. **D3 真人双标未过**：依赖 `reference` 的 CR / CP 绝对值继续打折，不能写「评估体系已闭环」。
5. **小样本只作线索**：`multi_hop` / `instruction` / `boundary` 各 3 题、rerank 20 题分层抽样，都不作统计结论。
6. **两处「没修好」要如实说**：`app/` 暂无 RAG 检索端点，`ivfflat.probes` 接线只是收敛入口 + 测试，**不等于线上已修好**；`g049` 是应拒答却基线就没拒答的题库质量问题，本次未改题库。

## 4. 周复盘三问

**① 本周做出了什么能演示的东西？**
一套可复现的评估闭环：冻结语料（330 块）→ 50 题 golden set + 标注规范 → 四项全量基线与分组报分 → 两轮单变量 A/B（生成 prompt、rerank）→ 独立裁判与换裁判门禁 → 非 LLM 的 CI 门禁 → DEC-039~046 决策日志。演示路径：`README.md` → `evals/RAGAS_BASELINE.md` / `ATTRIBUTION.md` / `RERANK_RECHECK.md` / `REFUSAL_AB.md` / `CI_EVAL_GATE.md`。

**② 哪个概念只会用、说不出为什么？（→ 下周补）**

- `LLMContextPrecisionWithReference` / `LLMContextRecall` 的判定链：为什么拒答题 CP 恒等 1.0，而 CR 明明不读 `response` 也会漂 0.25？（裁判分批漂移还是 reference 形态导致？）
- D3 验收指标口径没对齐：`ANNOTATION.md` 写 Cohen's κ ≥ 0.8，`ACCEPTANCE.md` 用逐题完全一致率 ≥ 0.8，真人来标之前得先定死用哪个。
- IVFFlat `probes` 与召回率 / 延迟的理论关系：只测了默认 1 vs 3 的实测差异，说不清近似搜索的召回下界。

**③ 作品集多出来的那一层，3 分钟能不能讲清？**
一句话：**从「能跑 RAG」到「能证明一次改动该不该上线」**。三段：① 先把尺子做出来（冻结语料、标注规范、全量基线、分组报分，并承认标注一致性还没过真人验收）；② 再量尺子本身（用不读回答的 CR / CP 当噪声标尺，换独立裁判做交叉验证，避免把裁判漂移当提升）；③ 最后让尺子拦住改动（两次 A/B 都判定不采纳，把结论写进 DEC，并接一条不花钱的 CI 门禁防回归）。
