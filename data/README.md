# data/ · 样例数据

> ⚠️ **本目录只放自造的、同构的样例文档。真实单位资料一律不入库。**

## 为什么自造

作品集需要公开才有求职价值，而数据源涉及财务制度。自造数据不是妥协——它反而更好用：

- 能**主动设计难例**（条款冲突、跨文档引用、应该拒答的问题），真实数据往往「刚好能用」但覆盖不到边界
- 零合规风险，可以放心演示

## 规划中的数据

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| `sample-policies/` | 自造的财务/资金制度文档（Markdown） | RAG 检索源 |
| `golden_set.jsonl` | 50–100 题 + 标准答案 + 应拒答题 | W6 评估基准 |

## 目录约定

- `raw/`、`processed/` 已在 `.gitignore` 中忽略 —— 中间产物不入库
- 只有**小而稳定**的样例文件才提交
